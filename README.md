# Oaklands High School — Independent Redesign Concept

An **unofficial, independent website redesign demonstration**. This is not the official Oaklands High School website.

The planned site features responsive navigation, slow navy-to-blue animated banners, a school gallery, announcements, a calendar, document centre, and a browser-local demonstration staff editor.

**Demo limitations:** Staff login is simulated and provides no real authentication. Content updates are stored only in the visitor's browser. Several images are linked from third-party sources; copyright and learner-image permissions have not been verified. Photographs should be cleared before the site is publicly shared or presented as a school-approved publication.

Official school website: https://oaklandshighschool.co.za/
