OAKLANDS HIGH SCHOOL — ENHANCED INDEPENDENT REDESIGN DEMONSTRATION

HOW TO OPEN
- Extract the full ZIP and open index.html in Firefox or Chrome.
- Navigate from the top menu to Updates, Calendar, Documents and Admissions.
- To try content editing, open staff-demo.html directly (this page is deliberately not in the public navigation). No password is implemented.
- Add sample announcements/events/documents. Changes appear in the same browser on the public pages. You can export/import JSON and reset to the sample content.
- File uploads up to 1.5 MB are stored as browser local data and consume browser storage; do not upload sensitive files.

IMPORTANT LIMITATIONS
- This is a LOCAL STATIC PROTOTYPE with browser localStorage, NOT a secure multi-user school website or production CMS.
- Data does NOT sync to visitors' browsers, other computers or deployed servers. An export is necessary to move demo content between devices.
- No actual school announcements, events, fees, admission deadlines or documents are invented. Sample records are prominently labelled DEMO.
- No online admissions, secure accounts, visitor data collection, live messaging, backend storage, or email submission is implemented.
- Contact links open the visitor's email application. No message is automatically sent.
- Independently created concept, not official or endorsed. Obtain permission before a public marketing/demo release using school logo, images or other owned content.

FILES
- All legacy pages are retained, with new pages: updates.html, calendar.html, documents.html, admissions.html, staff-demo.html.
- portal.js powers the browser-local content editor, updates, calendar and downloads.
- styles.css retains the approved navy/gold design with responsive enhancements.

FOR PRODUCTION
1. Confirm correct/current school content with authorised staff and obtain permissions for branding/media.
2. Implement authenticated staff CMS with roles, backend database, server-side file storage, backups and audit history.
3. Configure school-approved domain, secure HTTPS hosting, monitoring and maintenance.
4. Review WCAG accessibility, security, POPIA compliance, mobile speed and contact workflow.
5. Test with staff and families before launch.

PHOTO GALLERY ENHANCEMENT
- Visit gallery.html from the public menu.
- Open Staff Login > Staff Demo, scroll down to Staff Media Manager.
- Add JPEG/PNG/WebP image; browser compresses to JPEG. Select Use on homepage.
- Gallery changes exist only in the same browser/profile (localStorage).
- Export gallery JSON to make backups.
- All initial tiles are placeholders, not actual school photographs.
- Use only approved school images and avoid learner photographs without appropriate permission.
